# SAP CAP Resources

## Knowledge

- [capire: Domain Modeling](https://cap.cloud.sap/docs/guides/domain/index)
  Official CAP guide to entities, associations, aspects, managed data. Use for: every CDS modeling lesson.
- [capire: Common Types and Aspects (@sap/cds/common)](https://cap.cloud.sap/docs/cds/common)
  Defines `cuid`, `managed`, `temporal`, `Country`, `Currency`, `Language` and code lists. Use for: reuse aspects and types.
- [capire: Core Concepts of CAP](https://cap.cloud.sap/docs/get-started/concepts)
  How domain models, service models and separation of concerns fit together. Use for: orientation, the "why" behind CDS.
- [capire: The Bookshop Sample](https://cap.cloud.sap/docs/get-started/bookshop)
  Worked example of a complete domain model with Books, Authors, Genres. Use for: a reference model to compare your own against.
- [capire: Getting Started](https://cap.cloud.sap/docs/get-started/)
  Install `@sap/cds-dk`, `cds init`, `cds watch`. Use for: environment setup and the inner dev loop.
- [capire: CDS language reference](https://cap.cloud.sap/docs/cds)
  Definitive CDL/CSN/CQL reference. Use for: exact syntax questions.
- [capire/bookshop on GitHub](https://github.com/capire/bookshop)
  Runnable sample project. Use for: cloning and reading real project layout.
