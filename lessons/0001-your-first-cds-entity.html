CDS Modeling · Lesson 1

Your first CDS entity

Win: you write one entity in CDS, predict the SQL table the compiler will produce, then check your prediction against the real compiler.

The idea

CDS is CAP's modeling language. You describe what your domain looks like, not how to store it, and CAP provides generic implementations from that model.[1] The model is the source of truth; the SQL table is a by-product.

Four things to know

1. An entity is a named set of elements (fields), each with a built-in type such as String, Date, Boolean, Integer or UUID.[1]

2. cuid is a reusable aspect from @sap/cds/common. It is shorthand for key ID : UUID, and the runtime fills in the UUID for you.[2]

3. managed adds four elements: createdAt, createdBy, modifiedAt, modifiedBy, filled automatically on insert and update.[2]

4. A namespace prefixes your entity names. In the generated SQL the dots become underscores (verified below on the real compiler).

using { cuid, managed } from '@sap/cds/common';
namespace sap.learning.onboarding;

entity SupplierRequests : cuid, managed {
  name        : String(100);
  country     : String(2);
  requestedAt : Date;
  approved    : Boolean default false;
}

Your task (about 10 minutes)

Before you run anything, take a piece of paper and write down: (a) the name of the SQL table, (b) every column. Don't scroll up. Retrieval from memory is what makes this stick.

Then, in a terminal:

npm i -g @sap/cds-dk
cds init supplier-onboarding
cd supplier-onboarding

Create db/schema.cds and type the entity above yourself (don't paste). Then compile it:

cds compile db/schema.cds --to sql

Compare with your paper. Every column you missed or mis-named is the useful part. Then change one thing (add an Integer element, rename the namespace) and predict the new SQL before compiling again.

Runnable check: the compiler prints one CREATE TABLE statement and no errors, and your prediction matched it. Be ready to explain to your teacher where each column came from: your elements, cuid, or managed.

Quick check

What does cuid add to an entity?

cuid is key ID : UUID, per the common aspects reference [2].

Which elements does managed add?

Four elements: who and when it was created, who and when it was last modified [2].

With namespace sap.learning.onboarding; and entity Foo, what is the SQL table name?

The compiler joins namespace and name with underscores. You saw this on the real compiler for SupplierRequests.

Where do you write the CREATE TABLE statement for your entity?

CDS captures intent (what, not how); SQL is generated from the model [1].
