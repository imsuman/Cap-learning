Reference

CDS modeling

Skeleton

using { cuid, managed } from '@sap/cds/common';
namespace my.app;
entity Things : cuid, managed {
  name : String(100);
}

Terms

Entity: named set of elements, becomes a table.
Element: a field with a type.
Aspect: reusable bundle of elements you mix in with :.
cuid: key ID : UUID, auto-filled.
managed: createdAt, createdBy, modifiedAt, modifiedBy.
Namespace: name prefix; dots become underscores in SQL.

Built-in types

UUID, Boolean, Date, Time, DateTime, Timestamp, Integer, UInt8, Int16, Int32, Int64, Double, Decimal, String, LargeString, Binary, LargeBinary.

Commands

cds init <name>
cds compile db/schema.cds --to sql
cds watch
